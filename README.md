# Projeto Integrador — Segurança da Informação

**Disciplina:** Segurança da Informação — Unit

**Equipe:** Eduardo Andrade Almeida, Gabriel Lima de Carvalho e Hyago Oliveira Costa

**Docente:** Ana Carla do Nascimento Santos

Este repositório reúne as entregas do Projeto Integrador: Segurança Aplicada ao
Desenvolvimento. O projeto aplica mecanismos de segurança por meio de implementações,
testes, evidências e documentação técnica, conforme os materiais da disciplina.

| Entrega | Tema | Documentação |
| --- | --- | --- |

## Organização

```text
README.md                    — visão geral do projeto
requirements.txt             — dependências da Entrega 1
entregas/
    entrega-1/               — código e documentação da Entrega 1
    entrega-2/               — código, testes, evidências e documentação da Entrega 2
```

Cada entrega possui seu próprio README com a explicação da funcionalidade,
as tecnologias utilizadas e as instruções de execução. Consulte a documentação
da entrega desejada antes de executar seus comandos.

Os exemplos e testes utilizam dados fictícios em ambiente local. Os materiais da
professora orientam os requisitos de cada etapa.
